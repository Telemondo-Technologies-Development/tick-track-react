# Changelog
## v1.0.0 - Initial Release -  2026-01-05
### Features
- Offline-first ticket tracking using IndexDB (Dexie)
- Time In / Time Out shift tracking
- Automatic duration calculation
- Ticket and shift history display
- Delete confirmation modal for tickets and shifts
- Responsive UI using Tailwind CSS
- Tab-based navigation (Ticket / Time In-Out) from shadcn

### Improved
- UI consistency and spacing
- Mobile responsiveness
